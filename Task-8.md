# TASK - 8: AWS Observability

## Objective
Explore AWS observability, understand the main observability concepts and commonly used AWS services, and document how they help DevOps teams monitor, troubleshoot, audit, and improve applications and infrastructure.

## Scope
The documentation focuses on commonly used AWS observability services and capabilities that can be explored within AWS Free Tier/free usage allowances when usage remains within the applicable limits.

## Work Completed
- Studied the fundamentals of observability.
- Learned the three main observability pillars: metrics, logs, and traces.
- Explored Amazon CloudWatch for monitoring, logs, alarms, and dashboards.
- Explored AWS CloudTrail for API activity and auditing.
- Explored AWS X-Ray for distributed request tracing.
- Explored Amazon Managed Service for Prometheus for Prometheus-compatible metrics.
- Explored AWS Distro for OpenTelemetry (ADOT) for collecting and exporting telemetry.
- Explored VPC Flow Logs for network traffic visibility and troubleshooting.
- Documented common DevOps use cases and cost/free-tier considerations.

## Key Understanding
- **Metrics** show numerical measurements such as CPU utilization and request counts.
- **Logs** record events and application/system messages.
- **Traces** show how a request moves through services.
- Observability combines these signals to help teams detect problems, investigate root causes, and understand system behavior.

## Service Summary

| Service | Main Purpose |
|---|---|
| Amazon CloudWatch | Metrics, logs, alarms, dashboards, and monitoring |
| AWS CloudTrail | API activity and auditing |
| AWS X-Ray | Distributed tracing |
| Amazon Managed Service for Prometheus | Managed Prometheus-compatible metrics |
| AWS Distro for OpenTelemetry (ADOT) | Telemetry collection and export |
| VPC Flow Logs | Network traffic visibility |

## DevOps Relevance
AWS observability helps DevOps teams monitor infrastructure and applications, detect failures, troubleshoot incidents, audit changes, understand application performance, and improve system reliability.

This task provided a practical foundation in AWS observability and the role of metrics, logs, traces, auditing, telemetry, and network visibility in DevOps. The detailed documentation explains the purpose, usage, examples, and cost considerations for the selected AWS services.
