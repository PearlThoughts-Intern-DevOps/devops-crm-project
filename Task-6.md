# TASK - 6: AWS & GCP

## Objective
Explore Amazon Web Services (AWS) and Google Cloud Platform (GCP), understand cloud computing fundamentals, learn commonly used cloud services, and compare similar services offered by both platforms.

## Work Completed
- Studied cloud computing fundamentals and benefits.
- Explored AWS and GCP platforms.
- Learned commonly used compute, storage, database, networking, container, security, monitoring, and serverless services.
- Prepared a comparison and service mapping between AWS and GCP.
- Documented the concepts, definitions, purposes, and common use cases.

## Key Concepts Learned
### Cloud Computing
Cloud computing is the on-demand delivery of computing resources such as servers, storage, databases, networking, and software through the internet.

### AWS
Amazon Web Services is a cloud platform providing services for compute, storage, databases, networking, security, containers, monitoring, analytics, and more.

### GCP
Google Cloud Platform is Google's cloud platform for building, deploying, and operating applications using infrastructure and managed cloud services.
